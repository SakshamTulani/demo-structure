# Client: Intellicar

Written by `/sf-new-project`. Keep it current.

## Who they are

Intellicar builds fleet telematics products. This project is internal: it is not built for an outside client.

## What they need from us

A small, runnable app that shows how a project made with sf-factory is structured, so teams can see the frontend architecture (stores, events, app state, modules) working before they start a client project.

## Constraints

Uses only a free public API with no key. Writes go to a shared public sandbox, so the demo must stay small and harmless.
